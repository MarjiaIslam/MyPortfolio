Research

COHERE: Cross-Cohort Harmonization for Spatial Proteomics

Undergraduate Thesis

Cell-type annotation across seven public cancer cohorts (about six million cells), using marker harmonization, rank-based normalization, masked-marker pretraining, and prototype classification with leave-one-cohort-out evaluation.

GitHub Repository

BioTheraX: Explainable Multi-Omics ML for Breast Cancer Treatment Selection

Manuscript Under Review

Explainable ML framework on METABRIC clinical, gene-expression, and mutation data across eight treatment categories, using XGBoost, LightGBM, CatBoost, Random Forest, and SHAP.

GitHub Repository

Lightweight Electricity Load Forecasting

In Progress

Short-term demand forecasting with a GRU model, lag-aware execution, and dynamic CPU/GPU scheduling, evaluated on accuracy, latency, and memory use.

GitHub Repository

XrVit: ChestX-ray14 Classification & Distillation

In Progress

14-label chest X-ray classification with CNN baselines and teacher-to-student knowledge distillation, compared on macro-AUROC, F1, calibration, and patient-level confidence intervals.

GitHub Repository
